# 海洋生物入侵 · 局域网双人十一关战役预览

联机适配保持在 `online/`；本次经授权扩展共享 `game_core/` 与 PNG 素材，PC、Web 单机与联机复用同一份十一关定义、Boss AI、碰撞和伤害。原启动入口与根依赖不变。

**目前是待真实浏览器/手机验收的预览实现，不是已确认全平台可用的发行版。** 详见 [测试报告](TEST_REPORT.md)。包含原游戏全部 11 个普通关卡及其 Boss，关卡间沿用原过渡，第十一关通关后结束。**不含无限模式**。

## 运行方式

一台电脑运行 Python 权威服务器，两名玩家分别打开浏览器。服务器电脑可以同时作为 P1；两部手机游玩仍需要第三台电脑运行服务器。同一 Wi-Fi 必须允许设备互访。没有公网部署、账号或外部联机服务。

以下命令从项目根目录执行，使用独立 Python 3.12 环境，不要更改原单机环境。

macOS / Linux：

```sh
python3.12 -m venv online/.venv
source online/.venv/bin/activate
python -m pip install -r online/requirements-server.txt -r online/requirements-build.txt
python -m online.tools.build_web
python -m online.server --http --host 0.0.0.0 --port 8765
```

Windows PowerShell：

```powershell
py -3.12 -m venv online/.venv
.\online\.venv\Scripts\Activate.ps1
python -m pip install -r online/requirements-server.txt -r online/requirements-build.txt
python -m online.tools.build_web
python -m online.server --http --host 0.0.0.0 --port 8765
```

首次安装/构建需要联网下载固定版本 Pygbag/WASM 和中文字体。构建约 120 MB，输出 `online/build/web/`，缓存/暂存为 `online/.web-build/`；运行时网页资源在本机，不依赖公网 CDN。服务端依赖不打包进浏览器。预览不注册离线 Service Worker，联机必须持续连接服务器。

默认只监听 `127.0.0.1:8765`，只有显式 `--host 0.0.0.0` 才供局域网访问。端口被占用会报错，不会结束别的程序。请不要做路由器端口映射或暴露到公网。`--http` 是明确选择的不加密局域网调试方式，不适合不可信网络。

更推荐使用设备已信任、覆盖主机 IP 的证书：

```sh
python -m online.server --host 0.0.0.0 --port 8765 --cert /path/to/cert.pem --key /path/to/key.pem
```

证书/私钥必须放在静态目录 `online/build/web/` 外。程序不会自动安装证书、修改信任/防火墙或绕过浏览器警告。已有单机证书可以由你指定，但不会自动复制或改写。HTTPS 页面连接同源 WSS。

## 两人进入

1. 主机终端显示地址与六位房间码。电脑本机打开 `http://127.0.0.1:8765/`；其他设备打开终端显示的电脑局域网 IP（如 `http://192.168.1.23:8765/`）。HTTPS 使用对应 HTTPS 地址。
2. 引擎加载完成后，按页面提示点击/触摸一次，再输入同一个房间码。先加入的是 P1，后加入的是 P2。
3. 双方点击「准备」，P1 选择简单/中等/困难并开始。第三名玩家会被拒绝。
4. 电脑：WASD 或方向键移动，空格射击，Q/E 技能，R 辐射激光，F 飞镖，B 打开商店。手机：左摇杆、右侧射击/技能，支持同时触摸。
5. 角色与武器通过商店选择。提示「队友正在使用」时先让队友切走。所有购买与装备结果以服务器状态为准。

断线或页面隐藏会暂停全局；重新连上同一房间的原页面后恢复。当前标签页的 sessionStorage 保存临时重连令牌，不上传第三方。不要复制令牌给别人。关闭标签页、清除站点数据或换浏览器可能丢失席位；首版没有踢人/换人界面，此时由主机停止并重开服务器获得新房间。

## 已实现规则

- 共享金币、共享 **5 次复活生命**；各自独立血量（原难度：6/5/4）。
- 每漏一只怪，**每名仍存活玩家各扣 1 HP**，所有难度相同；不直接扣共享复活次数，也不伤害已经阵亡的玩家。漏怪伤害不被临时无敌抵消。
- 阵亡后该玩家自己点击复活。先消耗一次共享生命，用尽后才扣共享金币，简单/中等/困难分别 50/75/100；复活补满本人血量并获得短暂无敌。
- 一人阵亡时队友继续战斗。两人都阵亡但资源足够时等待确认复活；两人都阵亡且资源不足时结束。
- 购买的角色/武器两人共享所有权，同一件只能一人装备，渔夫和手枪例外。阵亡玩家保留其装备占用直到换装/复活。
- 任一人打开商店会让双方进入商店暂停状态，**双方分别关闭后**才继续。暂停期间战斗时间与技能冷却都停止。
- 共享十一关刷怪、子弹、角色技能、礼包、动画、Boss 行为通过原核心复用；不是重新写的简化玩法。画面复用原 Pygame 渲染。

- Boss 通关奖励沿用原金币与治疗量，治疗分别给仍存活的玩家，不自动复活阵亡者。
- 第九关废弃工厂与第十关远古神庙各有三种新小怪和四技能 Boss；第十一关直接挑战原八岐大蛇。所有平台加载相同 PNG 特效和共享核心。

## 架构与限制

- 服务器只接收移动、射击和操作意图，独自计算 60 Hz 战斗；完整视觉状态约 20 Hz 广播。网络慢时只保留最新帧，不积压历史快照。
- 浏览器 Pygbag 通过 JavaScript 原生 WebSocket 桥接收发，不在 WASM 中使用 Python socket/线程；客户端只绘制，不计算伤害和奖励。
- P1 在大厅选择双方统一方向（默认当前窗口方向）：横屏 960×720 或竖屏 480×720。两人方向都匹配、引擎加载完成并准备后才能开始。方向选择变更会清除双方准备状态。
- 对局中不能更改房间方向。任一设备旋转到不匹配方向时，主机暂停推进并清除输入；双方重新匹配后继续。断线、后台隐藏和商店暂停仍独立有效。重连必须重新报告实际方向。浏览器只缩放/留边，不旋转输入坐标，不依赖 iOS 不支持的方向锁定。
- 暂无客户端位置预测/快照插值，画面更新平滑度仍待手机实测；不是原单机的自适应战场布局。
- 单进程只允许一个双人房间。不能把本适配器当成多房间库；原核心使用全局时钟/几何状态。
- 安全检查包含同源 Origin、局域网 Host、房间码、随机重连令牌、严格 JSON 字段、递增序号、消息大小/频率限制、旧对局消息拒绝。只分发联机构建目录，不暴露项目根目录或私钥。
