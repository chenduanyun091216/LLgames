# 网页版使用与部署

先按 [项目 README](../README.md) 安装依赖并激活共用的 `.venv`。以下命令均从项目根目录执行。

## 本机试玩

```sh
python run_web.py --http --host 127.0.0.1
```

打开 `http://localhost:8001/`。首次构建需要联网，产物位于 `build/web-offline/`。

## 局域网 HTTPS

内置服务默认使用 HTTPS，监听 `0.0.0.0:8001`。如果已有手机信任的 PEM 证书和私钥，可以直接启动：

```sh
python run_web.py --cert /path/to/cert.pem --key /path/to/key.pem
```

### macOS 生成局域网证书

在自己的局域网测试时，可用 [mkcert](https://github.com/FiloSottile/mkcert) 生成证书。将下面的 `192.168.1.23` 改成这台电脑实际的 Wi-Fi IP：

```sh
brew install mkcert
mkdir -p .web-build/tls
CAROOT="$PWD/.web-build/tls" mkcert -cert-file .web-build/tls/cert.pem -key-file .web-build/tls/key.pem localhost 127.0.0.1 192.168.1.23
python run_web.py
```

### Windows 生成局域网证书

使用 Windows 包管理器安装：

```powershell
winget install --id FiloSottile.mkcert -e
```

安装后重新打开 PowerShell，进入项目根目录并重新激活 `.venv`。运行以下命令设置本次会话使用的 `mkcert`：

```powershell
$mkcert = 'mkcert'
& $mkcert -version
```

如果仍提示无法识别 `mkcert`，可以直接使用 WinGet 安装的可执行文件。以下是 WinGet 默认安装目录的示例，实际位置不同则替换为本机的 `mkcert.exe` 完整路径：

```powershell
$mkcert = "$env:LOCALAPPDATA\Microsoft\WinGet\Packages\FiloSottile.mkcert_Microsoft.Winget.Source_8wekyb3d8bbwe\mkcert.exe"
& $mkcert -version
```

如果没有 `winget`，可从 [mkcert 官方发布页面](https://github.com/FiloSottile/mkcert/releases) 下载 Windows 版本，再将 `$mkcert` 设为下载的可执行文件的完整路径。

在同一个 PowerShell 窗口执行 `ipconfig`，找到当前 Wi-Fi 或以太网的 IPv4 地址。把下方示例中的 `172.20.10.4` 换成实际地址。

```powershell
New-Item -ItemType Directory -Force -Path .web-build\tls | Out-Null
$env:CAROOT = (Resolve-Path .web-build\tls).Path
& $mkcert -install
& $mkcert -cert-file .web-build\tls\cert.pem -key-file .web-build\tls\key.pem localhost 127.0.0.1 172.20.10.4
python .\run_web.py
```

`-install` 会让 Windows 信任本地根证书。上面的 `CAROOT` 将根证书放在 `.web-build\tls\rootCA.pem`，启动脚本会自动读取它。请跳过 `Copy-Item`，因为从该 `CAROOT` 复制到同一路径会报「无法使用项其自身覆盖该项」。如果你沿用其他目录中的根证书，可以在启动时通过 `--setup-ca` 指定该目录下的 `rootCA.pem`。

### 手机信任证书

手机和电脑连接同一局域网后，首次使用请打开终端显示的 HTTP 安装入口（默认 `http://电脑IP:8000/`），下载并信任根证书，再点击「进入 HTTPS 游戏」。安装入口只提供说明和公共证书。自备证书时可用 `--setup-ca /path/to/rootCA.pem` 开启此入口，端口可通过 `--setup-port` 修改。

- iPhone：用 Safari 下载，在设置中安装已下载的描述文件，再到「通用 → 关于本机 → 证书信任设置」开启完全信任。
- Android：在系统设置中搜索「安装 CA 证书」，选择下载的 `rootCA.cer`。

默认游戏地址为 `https://电脑IP:8001/`。Windows 上无法连接时，检查防火墙是否允许 Python 的局域网访问。请保管好 `.web-build/tls/` 内的 `rootCA-key.pem` 和 `key.pem`。电脑 IP 改变后，用同一 CA 为新 IP 重新签发证书，新地址也会单独缓存。

## 游玩与画质

加载完成后点击或触摸一次，浏览器才允许游戏播放音频。战役和无限模式见 [战役与无限模式](战役与无限模式.md)。

Web 端提供单人游玩、摇杆、手动和自动射击、武器切换、角色技能和商店。横屏时战斗集中在中间半屏，角色和敌人缩为 PC 端尺寸的 64%；竖屏为 80%。菜单、商店和战斗文字在独立画布上按设备像素比绘制，最高 3×；战斗画面缩放使用平滑采样，水下气泡和战斗光效只参与绘制；战斗和触控继续使用原来的逻辑坐标。

在暂停菜单的画质设置中，可即时切换「标准」「默认」和「高清」。首次进入时使用「默认」，三档均显示当前视口对应的渲染分辨率。默认档取标准和高清渲染比例的中间值，并使用高清素材。标准以 60 FPS 为目标，按视口的 1.15 倍渲染，画布长边和短边分别最多 1800 和 960 像素。高清也以 60 FPS 为目标，画布短边最多 1080 像素，长边最多 2560 像素。三档保持视口比例和 60 Hz 战斗逻辑，实际帧率随设备与场景负载变化。游戏地址加上 `?perf=1` 可以查看实时画布尺寸和各阶段耗时。

## 构建、离线与自托管

首次构建需要联网下载固定版本的 Pygbag、Pygame 和中文字体，生成的 `build/web-offline/` 自带这些资源。PC 直接加载 `assets/images/` 的共享母图。Web 构建用 Lanczos 生成两档副本，默认的背景与战斗精灵尺寸上限为高清的 75%，从原图等比缩小。高清横版背景限制在 2160×2160，竖版背景限制在 1600×2400。透明精灵以 PNG 保存，动画逐帧缩小再拼回原布局，普通动作每帧最长 288／384 像素，八岐大蛇和远古巨鲸保留更大的帧。两档共用无需重复存放的素材，画质可离线切换。修改 Web 源码或母图后，重启会自动重新构建。`--force` 强制重建，`--build-only` 只生成文件。

- **HTTPS 或本机 localhost**：游戏加载后会自动保存离线资源。看到“离线资源已保存”后，可以关闭电脑服务，手机断网也能在同一浏览器中重新打开原地址。浏览器清理站点数据后需要联网重新保存。上线新版本时，浏览器会在联网访问时下载新版，关闭所有游戏页面再打开可让已下载的新版接管。
- **普通局域网 HTTP**：可用 `python run_web.py --http` 调试，后续访问仍需连接服务器加载入口。

自托管时，将 `build/web-offline/` 作为站点目录，保留 `Cross-Origin-Opener-Policy: same-origin`、`Cross-Origin-Embedder-Policy: require-corp`，为 WASM 返回 `application/wasm`。入口和 `sw.js` 应重新校验，带版本的资源可长期缓存。内置服务器已提供这些响应头和 gzip 传输，可放在 HTTPS 反向代理后使用。
