# TTgames 五个独立游戏模式实施方案

本目录是交给开发 agent 的任务书。五个模式都属于交付范围，每个都有独立入口、操作、胜负、结算和再来一局。文中数值是首版可实施的设计初值。基线为 2026-11-26 本地仓库 `ac578c0`，后续实施以当时工作区为准。

## 要做出的游戏

| 首页玩法 | 人数与类型 | 玩家一局做什么 | 首版完整内容 |
| --- | --- | --- | --- |
| [横版突围](01-side-scroller.md) | 单人或局域网双人合作，侧视平台动作 | 自己控制前进节奏，跑、跳、趴、八方向射击，越过高低两条路线抵达出口 | 港口货轮、钻井平台、海底隧道三幕，可从任一幕练习，也可连续撤离 |
| [深潜寻宝](02-deep-dive.md) | 单人，无战斗探索 | 选海域、装两件工具、潜入搜寻，用氧气和载重决定何时返航 | 三个海域、三种工具、九种藏品、本地图鉴和航次收入 |
| [双人潜艇快递](03-sub-courier.md) | 局域网双人合作，无战斗 | 舵手看航道，轮机员管压载、动力和货物，途中可以交换岗位 | 玻璃水母、港口急件、熟睡幼鲸三种有不同操作要求的订单 |
| [潮汐竞速](04-tide-race.md) | 单人计时或局域网双人竞速，无战斗 | 骑飞鱼借浪起跳、俯冲接浪，在海面与水下路线之间争取时间 | 三条赛道、分段计时、本地最佳航迹、双人同场比赛 |
| [今天我当 Boss](05-boss-duel.md) | 局域网双人非对称对战 | 一人操纵冒险者，一人亲自瞄准并施放首领技能，换边再比 | 巨鲸、机械蜥蜴、八岐大蛇三套可操作技能，两回合公平结算 |

《魂斗罗》式横版在本项目中指侧面观察、重力落地、多层平台、向左右移动和随人推进的镜头。手机旋转只改变显示布局。深潜、快递和竞速均可在零击杀、零武器配置下完成。

## 入口和平台

- 原生 PC 与主网页版使用同一份 Python 模拟。统一首页增「玩法大厅」，里面平列战役、无限和五张新模式卡，按可玩人数分流。保留原有单机、创建、加入入口与原菜单快捷键。局域网中的模式由房主选择。
- 每张卡显示玩法、人数、目标与实际可用按钮。双人专属卡提供「创建房间／加入房间」。从首页卡创建后，房主进入预选该玩法的大厅。受邀者在自己设备看到同一配置。支持单人的卡可离线开局。
- 独立 Phaser 是另一款单机网页客户端。计划包含横版突围、深潜寻宝、潮汐竞速的原生 JS 单人移植。双人按钮通过可配置的主网页版地址进入已有联机服务。部署者可以只发布独立单机站，届时联机入口显示所需条件。
- 局域网按现有两席房间设计。单人游玩指一台设备一名玩家，双人游玩指一人一台设备，可用原生 PC 或主网页。首版记录和图鉴保存在当前设备。以上是便于直接开工的产品默认值。

## 如何分批实施

| 工作包 | 前置 | 做完时从正常入口能看到什么 |
| --- | --- | --- |
| F0 单机接入 | 现有工程 | 首个真实模式可从首页启动、暂停、恢复、结算和返回，主 Web 构建含新包和数据。与第一个单人模式一起交付 |
| F1 房间接入 | F0 的模式标识、输入与时钟 | 两个客户端能在同一真实新模式输入、暂停、断线恢复和结束。与首个有双人玩法的模式一起交付 |
| M1 横版突围 | F0，合作部分用 F1 | 单人完整三幕，双人合作、救援和过场 |
| M2 深潜寻宝 | F0 | 三海域完整收支和设备图鉴，可独立于 F1 实施 |
| M3 双人潜艇快递 | F1 | 两个不同岗位完成三种订单，可换岗 |
| M4 潮汐竞速 | F0，竞赛部分用 F1 | 单人最佳成绩和航迹、双人同场按抵达顺序判定 |
| M5 今天我当 Boss | F1 | 两人可任选三首领之一，在同场换边并产生最终赛果 |
| P 单人 Phaser、I 整体验收 | 对应模式的规则和数据稳定 | 三个单人版本有可比较的结果，双人跳转可用，五项能连续进出，旧战役和无限走通 |

推荐顺序为 **F0＋M1 单人 → F1＋M1 合作 → M3 → M2 → M4 → M5 → P／I**。先验证横版手感和异步设备上的双人协作，再扩内容。也可先从寻宝启动 F0，或从快递启动 F0＋F1。任取一包时，按下方指令补齐该包实际需要的接入。每份模式文档的第一段可玩内容是开发里程碑，最后列出的全部内容才构成该模式的首版交付。

## 可直接复制给 agent

**一次实施全套**

```text
在 TTgames 仓库实施 docs/plans/new-game-modes/README.md 的五个独立模式。先读 00-shared-runtime.md 和 06-integration.md，再逐个读模式文档。按工作包顺序从主首页实现并验证，完成相应单人、联机、Phaser 与内容清单。每个里程碑给出真实可复现的入口和结果，继续下一包。保留工作区已有修改。最终按 I 部分列出通过项、实际设备和待验项。
```

**一次实施一个模式**。以下每条都是独立指令，包含单模式所需的平台范围。共享接入和已完成模式可由后续 agent 复用。

## 交接与验收入口

- [公共实现约定](00-shared-runtime.md) 包括现有代码入口、首页和主循环、画布、数据、输入消息、快照、重连和存储。
- [跨端移植与整体验收](06-integration.md) 包括实际打包路径、验收矩阵、定向命令、设备检查及交付回执。
- 每包完成时记录实施基线、实际改动、已通过的验收编号和复现步骤。可试玩的平台、游戏逻辑测试、浏览器模拟和真机记录分别填写。数值调优需写清改动前后与促成调整的试玩现象。
