# M3 · 双人潜艇快递

[总任务书](README.md) · [共用运行时](00-shared-runtime.md) · [跨端验收](06-integration.md)

## 两个人分别在玩什么

`sub_courier` 需要两席局域网玩家。一人掌舵，从舷窗看航道、障碍、信标与泊位。一人值轮机，从剖面图看压载水箱、动力档、进水和货舱。轮机员改动装置后，舵手马上感到船的浮力、速度或噪声发生变化。目标是两人把指定货物运到收件泊位，取得共同评价。全程无战斗。

第一份可玩的切片为「装载水母 → 通过低顶窄洞 → 靠港签收」，要求两名真人分别提供驾驶和压载输入。正式首版有三份订单，每份约 2–4 分钟，出航前能看到货物规则、路线图标与预计时间。教学提示在相应岗位第一次需要动作时出现。

## 一趟订单的流程

1. 房主选择订单，P1 默认舵手，P2 默认轮机员。两席看到本人的职责和共有目标后准备。装货动画结束后开始计时。
2. 航线按三个可见地标推进。舵手先见到前方转弯／限高／静音区。轮机员先见到泵报警和货物异常。两人共有航段编号、剩余时间、船体与货物的简要状态。
3. 舵手将完整艇体驶入终点泊位，对地合速度 `hypot(vx, vy)` 严格低于 15 px/s 连续 60 个有效 tick。任一步出界或达到 15 时置零，暂停保留已有计数。第 60 步即可接受轮机员当步按下的「交货」。舵手还未到位时轮机台显示要满足的泊靠条件。签收一次后同时进入结果页。
4. 结果给出是否完成、星级、用时、货损或超时原因，以及两人的岗位记录。两人可交换岗位重送原单，或返回房间选下一单。

| 订单 ID | 路线与时限 | 货物的独有规则 | 评价目标 |
| --- | --- | --- | --- |
| `jelly` 玻璃水母 | 浅湾玻璃栈桥，9,600 px，时限 210 秒。低顶洞、浮箱、收件码头 | 货物完整度从 100 起。一次有效碰撞扣 12。轮机员提前切到静音低速档时，防震吊架落锁，本次扣 5。中段货架卡扣松动，指示亮起后可按住处理 1 秒锁紧。未锁紧时碰撞再扣 5 | 成功交付获得 1 星。完整度 ≥85 加 1，耗时 ≤145 秒再加 1 |
| `express` 港口急件 | 逆潮水道，13,200 px，硬时限 130 秒。可绕行安全航道或进短闸 | 文件筒防撞。走短闸需舵手驶入等待区、轮机员切压载下潜，尾门合上前穿出。中途一只螃蟹顶开货架，轮机员依照闪动的卡扣按住处理 1 秒，未处理时最高动力降至标准档 | 成功交付得 1 星。耗时 ≤112 秒加 1，船体 ≥75 加 1 |
| `calf` 熟睡幼鲸 | 海草廊与静潮湾，10,800 px，时限 225 秒。两段静音区、一道下沉水流、育婴码头 | 货舱惊醒值 0–100。静音区里使用强推每秒 +12，标准档 +3。静音档或关机每秒 −6，有效碰撞 +15，限制在 0–100。达到 100 则幼鲸醒来，本次特殊委托失败。舵手可借已标出的顺流漂行 | 成功交付得 1 星。最高惊醒值 <60 加 1，耗时 ≤175 秒再加 1 |

所有订单在时限归零、船体归零或该货物破损／惊醒时出具失败单。到港判定同 tick 顺序为先碰撞和货物损失、再验证交货、最后判时限。到时限的最后一步合格交货算成功，已经破损的货物不能签收。

## 两块仪表与操作

| 所在岗位 | 键盘、触控 | 具体影响 |
| --- | --- | --- |
| 舵手 | 左右／A、D 调整前进或倒车，上下／W、S 操作升降舵。左摇杆对应两轴。按住 J 或触控「慢靠」为 `held` 位 1 | 可微调升降并刹车，松开油门向当前海流速度衰减。画面提前显示限高、收件方向和当前外界水流 |
| 轮机员 | 上／下控制压载，按住时每秒改变 30 个百分点。J 或「动力」按下产生 `power_next`，顺序为标准 → 强推 → 静音 → 关机 → 标准 | 压载 0–100，50 为中性。改变上下浮力。动力档立刻改变航速上限与本单噪声。手机有独立加／减压载的按住键 |
| 轮机员 | K／「选设备」按下产生 `station_next`，循环泵、货架、交货台。按住 E／「操作」为 `held` 位 4，交货台按下单次产生 `deliver` | 仪表先显示正在处理的部件和进度。泵修漏、卡扣护货，交货台显示停稳状态。一次持续按住只完成当前操作，切换设备需要重新按 |
| 任一方 | L／「换岗」产生 `swap_request`。Tab／「信号」打开四个快捷语句 | 一方申请、另一方 3 秒内确认，在权威步边界同时交换。信号提供「下潜」「减速」「货舱异常」「可以靠港」，使用 `signal_dive / signal_slow / signal_cargo / signal_dock`，事件在对方视图显示 2 秒 |

舵手看得到船速、船的俯仰和粗略警告。轮机员看得到精确水箱、进水、舱货和当前动力，另有下一地标距离。两边能从图标和文字接收协作信息，关声音也能交货。交换后本人的 HUD、键位说明和可操作设备立即随岗切换。暂停、重连或改岗后清空旧的按住、短按与待确认换岗请求。

## 模拟与故障

- 采用宽 100、高 40 px 的侧视艇体。标准档最高前进 108 px/s，强推 150，静音 70，关机只受海流和惯性。倒车上限 50。「慢靠」把动力目标限为 12。速度以约 65 px/s² 逼近目标，不用完整流体引擎。
- 充分压载下沉、排载上浮。水箱偏离中点时给 `(ballast − 50) × 1.1` px/s 的纵向目标速度。升降舵在有动力时另给最多 ±26 px/s。分段水流给显式横纵分量。机舱仪表区分舵手发出的意图与当前实际速度。
- 船体初值 100。碰撞按法向入射速度处理，超过 35 px/s 才扣 15 船体。贴墙滑行或连续多 tick 接触同一面，在离开并重新撞击前只结算一次。累计两次重撞出现一个漏点，此后每秒扣 1 船体。轮机员选泵持续操作 2 秒关漏。上限一个活动漏点。艇体被推出障碍后仍能倒车调整。
- 每张航线用路段、洞口、海流、检查触发器、泊位和货物事件定义。收件泊位与前方至少 200 px 的减速段采用静水，段内横纵水流均为 0。泊位沿航向至少长 140 px，可容下 100 px 艇身并以 12 px/s 慢靠满 1 秒。所有关键地标能提前看到，急件的捷径失败后能走安全出口。用安全路线与捷径分别驶到泊位，核查实际用时和最后 60 步。订单途中无存档读档。断线冻结船的位置、倒计时、报警和损耗。
- 主动离席或最终超出重连期限时，本单中止，向仍在线席位显示「搭档离开，订单中止」。暂时断网允许原席位恢复原岗位。仍在房间的玩家可从最终快照读到中止原因。正常双人结算可以回房重选，仅剩一席时可返回首页建房。

## 落地位置与资产

建议 `game_core/modes/sub_courier.py` 管唯一船体、订单、岗位映射、签收。`assets/modes/sub_courier/` 管三条航线。把舵手外景和轮机员内景做成两个轻量绘图函数，读取同一个权威状态。快照包含 `role_by_slot / epoch / route_segment / hull / x,y,vx,vy / ballast / power / station / leak / cargo / slot_signals / dock_ticks / remaining_ticks / result`。客户端只传意图。轮机指令来自当前舵手时不生效。换岗由公共 `epoch` 阻止旧动作进入新岗位。

美术制作一套可读的驾驶舷窗、一套四状态动力面板、艇体／压载剖面、三种货箱状态、航道浮标、限高标记与码头灯。音效至少区分水流、档位、渗漏、卡扣闭合、幼鲸翻身、双方签收。状态变化同时有图形／文字反馈。可借用已有海洋背景色调和气泡，舱内 UI 需让首次玩家知道哪项能点、当前处理到哪一步。

| 实施段 | 产物 |
| --- | --- |
| C-A | F1 接入真实快递房，两个屏幕显示不同岗位。完成一趟无事故水母交货 |
| C-B | 加入压载、惯性、撞击、漏水、卡扣、换岗和无语音快捷信号。真实两人能从事故恢复 |
| C-C | 加入三订单专属规则、路线、评分和失败原因，实测三份均可完成 |
| C-D | 原生／网页交叉占两个岗位，验证重连、结算重开、移动端仪表。接 Phaser 的主网页联机入口 |

## 验收 C1–C8

| 编号 | 操作 | 通过表现 |
| --- | --- | --- |
| C1 | P1 创建水母单，P2 加入并准备 | 双方职责、路线和货物正确，两人各有可操作项目，只有一艘艇 |
| C2 | 舵手保持前进，轮机员改变压载再换动力档 | 两端看到同一艘艇穿过限高段，仪表与移动方向一致 |
| C3 | 撞墙后贴墙 2 秒，离开再撞。轮机员修漏 | 第一次接触只计一次，第二次产生漏点，修完停止损失 |
| C4 | 先后确认换岗，旧岗位在换岗边界按操作。再试一次请求超时 | 只有当前岗位动作生效。超时仍在原岗，两次结果可从双方画面辨认 |
| C5 | 用最快路线完成急件、故意超时。在幼鲸区分别关机漂行和持续强推 | 订单分别给准时、超时、静音通过或惊醒的结果，星级按表计算 |
| C6 | 从有水流的航段驶入三张图各自的静水泊位。分别以 12 和 15 px/s 尝试交货，再让第 60 个合格步与时限末步重合 | 12 可累计，15 清零。最后有效步可签收一次，两端数字一致。船体或货物已损毁时按失败处理 |
| C7 | 途中某人断线重连，再试主动离开 | 前者保留角色、货物和时间，后者共同订单中止，余下玩家能返回 |
| C8 | 原生当舵手、网页当轮机，再对调。手机双指压载／操作并旋转恢复 | 岗位键位、触控、提示和冻结恢复正确。可从结果再选另一单开局 |
