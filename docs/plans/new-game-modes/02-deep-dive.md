# M2 · 深潜寻宝

[总任务书](README.md) · [共用运行时](00-shared-runtime.md) · [跨端验收](06-integration.md)

## 玩家目标

`deep_dive` 是单人、无战斗的潜艇探索。每一趟从母船选择海域和两件工具，离港后用灯光寻找入口、开舱和装货。玩家随时可以返航，抵港时能看到哪些东西真的被运回、这一趟值多少、图鉴多了哪一格。常规水下目标为 1–2 分钟，按初始氧气和一次补气最多能潜 140 个有效秒，配装和结算另计。海域和工具从首局可选。动力、氧气和货重提供取舍。

第一次出海设计为可实际走通的短委托。码头灯照到罗盘，在它后方让玩家隔着舷窗看到价值更高的王冠。一条路线直接返港，另一条要先找到切割点。玩家能凭当时的氧气、返航距离和所带工具自行决定绕路。

| 海域 ID | 地形与往返 | 藏品示例，括号内为重量／收入点 | 本图的决策 |
| --- | --- | --- | --- |
| `wreck` 浅湾沉船 | 约 1,800×1,200。母船正下方为甲板裂口，货厅后有捷径闸与通至海面的竖井 | 铜罗盘 1／30、航海钟 3／75、船长王冠 4／130 | 罗盘稳定可取。切开舱门拿近路，或经船腹长廊绕到王冠 |
| `grotto` 回音洞穴 | 约 2,400×1,500。两处环路，固定灯带指向出口，中层有气囊与投放井 | 荧光贝 1／35、钟乳珍珠 2／70、晶簇 7／180 | 扫描可提前发现矿穴。大晶簇须用浮袋，取小件也可完成委托 |
| `observatory` 沉没观测站 | 约 2,600×1,650。观测塔、样本室和分段密封门，主通道有返航标志 | 铭牌 1／40、星盘 3／90、望远镜座 8／210 | 密封门缩短返程，大件有独立起吊井。在远处发现它后可为下一趟调整装备 |

地图用手工房间和连通口，至少准备两套预验证摆位。seed 选择摆位、普通货架位置和当次委托。码头、基础藏品、安全返航路线及起吊井始终可达。从任意两工具组合出航都能完成一项基础委托。海域首玩固定为教学摆位。重玩可选「同一海图」复现路线。九种藏品均须有可完成的取得方式与图鉴图像。

基础委托按海域分别要求签收铜罗盘、荧光贝和铭牌。重玩可在当前配装能取得的其他藏品中抽一件当目标。优先完成委托或提前返航都允许，结算分别展示「安全返航」和「委托已完成／未完成」。委托不另加收入，货物本身的收入按表只算一次。

## 资源、移动与工具

| 项目 | 首版初值与行为 |
| --- | --- |
| 船体和货舱 | 侧视水下自由移动，基础速度 120 px/s，斜向归一化，舱容 6。目标速度为 `120 × (1 − 0.045 × 当前总重量)` px/s，满载时为 87.6 px/s。松杆后用短阻尼停下，艇体与墙滑动接触。超容给出重量差，可在货舱选中一个实例原地卸下。 |
| 氧气 | 出发 120 点，每有效秒消耗 1。移动和等待都消耗，暂停冻结。低于 30／12 点时分别提示预计返航与危急状态。每图一处固定气囊，可停靠 2 秒补 20 点，每趟一次，上限 120。 |
| 切割器 `cutter` | 在带切线的闸门一艇身内持续使用 2 秒。每秒额外消耗 2 氧。中断保留本次航行已经切出的进度，进度满后永久打开该航次这扇门。 |
| 充气浮袋 `lift_bag` | 每航次 2 只，每只绑一件、最高承重 8。在带竖井标记的装货点使用，需连续操作 1 秒。大件生成在起吊点内。货舱中的小件也可在此主动上送。释放后 5 个有效秒由母船签收。 |
| 声呐 `sonar` | 每 8 秒可用一次，额外消耗 2 氧，显示 420 px 内可探索口、藏品轮廓及起吊井 3 秒。设备屏和声效同时提示，普通灯光足以找到基础藏品。 |
| 航次收益 | 所有已签收实例的收入之和。浮袋被母船签收后，即使后来缺氧也保住这一件。舱内物品须带回码头签收。个人纪录为各海域安全返港的最高单趟收入。图鉴按种类永久登记首次签收。 |

PC 用 WASD／方向键驾驶，E 拾取、卸货菜单或靠港确认，J／K 使用装备槽一／二，Tab 查看当前货舱，Esc 暂停。触控用左摇杆、两个带工具图标的按钮和一个就近交互键，轻点货舱可选物品卸下。切割和绑袋需要持续按住，声呐只认按下边沿。交互目标由最近距离、面朝方向和稳定 ID 排序。屏幕先显示当前将作用的对象。

返航指示沿已发现通道指向最近的下一路口，预计秒数按已知可通行路线长度除以当前载重速度，标为估算。算不到全程时显示最后已知的出口方向。灯光、返航线和氧量数字表达不同信息。低氧不会让屏幕完全变黑。

## 签收、失败与保存

1. 航次状态依次为 `outfit → diving → debrief`。母船码头区域内停稳，按 E 确认返港。空舱也能安全返回，收入取本航次所有唯一签收回执之和。既无回执也无待签收货物，才显示零收入。局中途主动撤退前显示会遗失的舱货，确认后只结算已签收项。
2. 每件宝物有 `run_id + instance_id`，其位置状态在 `world / hold / in_transit / delivered` 中取一项。拾取、卸货、绑袋和母船签收均针对同一实例。重复按键或重开结算页不会复制物品。卸在墙边时寻找艇体附近可达位置。
3. 一步内先完成到站的浮袋，再处理仍有资格的靠港确认，最后判断氧气耗尽。零氧与停靠确认在同一 tick 时，已进入码头且满足停稳条件则返港成功。正常返港后，先前放出的在途浮袋由母船收尾签收。紧急弃艇或缺氧时在途、舱内货物遗失。教学中实际演示一次袋子「运输中 → 已签收」。
4. 浮袋到船时立即写回执和图鉴。正常返港时用一次事务补签舱内及收尾浮袋，汇总该 `run_id` 的唯一回执并更新海域最佳。中断时已落盘的回执仍有效。重新打开应用回到母船，开新航次。局内地图、剩余氧气和未签收货物属于先前航次。
5. 图鉴显示九格、名称、发现海域和取得方式提示。首版收入用于本航次比较，不设扣款和解锁门槛。失败页分别显示「已送达」「遗失」和缺氧／主动撤退原因，可用同一配装重试。

## 技术与素材任务

建议新增 `game_core/modes/deep_dive.py`、`assets/modes/deep_dive/` 和持久化中的签收／图鉴操作。数据拆为海域、房间、门、连通边、起吊井、摆位和藏品目录。单个摆位记录 `instance_id / treasure_id / room / x / y`。先用确定摆位验证工具门与路网，再把 seed 选择放在初始化阶段。房间墙体参与艇体碰撞。未探索地形和声呐轮廓只影响呈现。地图 HUD 展示母船位置、已走过的门、货舱、氧表、当前对象与返航估算。

制作清单包括侧视微型潜艇、三套可辨认的舱壁／岩洞、码头光标、九个藏品剪影及发现图、工具图标、闸门开闭、浮袋上升和母船签收反馈。预览可以复用现有海洋色调和气泡效果。固定设施的造型应能让玩家在声呐和颜色提示关闭时认出入口、起吊井与补气点。

| 实施段 | 可验收的增量 |
| --- | --- |
| D-A | 沉船教学摆位，基础驾驶、拾取、卸货、靠港，结束时收入正确 |
| D-B | 氧气、三工具、浮袋运输和失败路径，补上持久化与重试幂等 |
| D-C | 三海域、九藏品、两种以上摆位、图鉴和返航路线。验证每一种装备组合可安全取得基础货物 |
| D-D | 主 Web 打包离线。Phaser 单人读同一地图与物品数据，以同一组签收样例对齐结算 |
