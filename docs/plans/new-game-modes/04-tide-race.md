# M4 · 潮汐竞速

[总任务书](README.md) · [共用运行时](00-shared-runtime.md) · [跨端验收](06-integration.md)

## 玩家目标与赛制

`tide_race` 是侧视飞鱼竞速。出发后有基础巡航，玩家利用浪头起跳，空中收翅俯冲，把落点接到下一道顺坡。玩得好时连续几次落水都能维持高速。玩家也能主动下潜走较难的海底近路。单人跑自己的最好成绩，局域网两人同时开跑，飞鱼互不妨碍。三条赛道均从首页可选。

首个可玩段由连续三个浪、一个分支、一个汇合门和一条终点线组成。普通玩家可以稳定游完，掌握接浪的玩家在同一路段能跑出可重复的优势。正式首版三个轨道均有完整计时、可见的中途门和结算。

## 赛道内容

| 赛道 ID | 长度／目标用时 | 赛段设计 | 分支和验证点 |
| --- | --- | --- | --- |
| `lighthouse` 灯塔折返湾 | 公共进度约 18,000 px／85–115 秒 | 起点平水，教学浪组，外海浮标，镜头绕灯塔后冲线。折返用后半段的新世界区段表现，公共进度一直增加 | 两种路线在 35% 分开、52% 汇合，海面大弯稳定，水下拱洞短约 12%。25%、60%、82% 为必经计时门 |
| `reef` 红珊瑚海峡 | 约 23,000 px／100–140 秒 | 小浪密集，随后有上下交错的珊瑚门，末段为长顺浪 | 32%–55% 分流。下路短约 16%，需要避开两组珊瑚。22%、62%、84% 记录分段 |
| `storm` 风暴外港 | 约 27,000 px／120–165 秒 | 前段可预测长浪，中段逆风，末段三连浪。泡沫线和风标显示下一起跳位置 | 48%–68% 分流。上路连续接浪，下路穿防波堤，短约 10%。24%、73%、88% 记录分段 |

每条赛道的种子、潮相和路段固定在 `track_version` 内，两名选手用同一套环境。改变有成绩影响的地形、海流、动作公式或发船条件时更新赛道或规则版本。美术重绘且碰撞数据相同可沿用旧航迹。

## 操作和可调手感

| 动作 | 键盘／手势 | 服务端判定 |
| --- | --- | --- |
| 加速、收速 | 右／D 追求速度，左／A 放缓。摇杆横轴同义 | 中立也持续巡航。降低速度可修正下一次落点，玩家可用单手先学基本接浪 |
| 借浪起跳 | 在水面按 J／触控「跃」，发送一次 `launch` | 浪面接近顶点时为强跳，普通位置为小跳。按住不会连跳 |
| 收翅俯冲 | 空中或水下按住 K／「潜」，`held` 位 2 | 空中加快下降，水下保持深度。松开后逐渐上浮。可同时给方向 |
| 选择路线 | 在蓝色鱼群标记处向下，`y > 0.5` 或按住「潜」。上路保持在水面 | 分流门内判一次。错过入口可继续走海面。水下分支内纵轴可微调深度 |

- 初始水平速度 175 px/s，中立目标 185，向前 215，收速 145。有连浪奖励时目标额外加速，硬上限 320。每秒以最多 60 px/s² 靠近目标。空中重力 680 px/s²，按「潜」额外加 460。普通跳向上速度 145，强跳 285。
- 初版浪面可用 `y = baseline − A × sin(2π × (x − wave_speed × t) / wavelength + phase0)`。沿赛段配置振幅 14–34 px、波长 210–380 px、传播速度 30–65 px/s。切段在平水区连接或做连续过渡。渲染与物理都读取同一浪面函数。t 从绿灯第一步开始计。
- 在水面且距最近浪峰水平距离不超过该波长的 14% 时可强跳，提前按下最多缓存 5 tick。空中下降穿过浪面才结算一次落水。落在向前下坡（`dy/dx > 0.12`）且收翅中，触发「接浪」，速度即时 +22、连击加一，最多三层，每层额外目标速度 +12 持续 2 秒、成功时刷新。普通落水保留基础巡航并清连击。撞障碍另行处理。
- 岩壁、浮标出口和水下洞口有明确轮廓。碰撞后原地减速至 110 并清连击，若困在实体内则回到当前分支的最近安全标记。回退时冻结该选手输入 24 tick，比赛计时继续。同一障碍连续接触只罚一次，直到离开。赛道无生命数。
- 灰盒用一条固定输入记录从起点连续接上三道浪，校准相位和间距。若三个提示浪的标准教学习惯无法连起来，调整赛段坐标，固定同一输入复验。首次进入灯塔可见「浪尖跃、下坡潜」的动图提示。接浪时让尾迹变长，音调随连击上升。

## 计时、捷径与航迹

1. `grid → countdown → racing → finished`。开赛倒计时 3 个有效秒，允许玩家预摆手指。绿灯时清空提前按下的起跳边沿，仍按住的方向可起步。记录 `start_tick / gate_ticks / finish_tick`，有效用时为 `finish_tick − start_tick`。
2. 每条分支记录自己的局部路程和映射到主赛道的公共起止进度。下路较短要由真实路径长度体现。合法前缀依次为起点、三道计时门和终点。越过某门只记一次，检查点复位保留已验证的前缀。走上／下路都须回到同一汇合门。排名用共同分段和映射后的进度，可显示对手领先多少。
3. 单人有效完赛才比较个人最佳。按 `track_id / track_version / rules_version` 分组。在第 0 tick、每 6 tick、分支切换、碰撞复位和冲线时采集 `[tick, world_x, world_y, pose, branch]`。坐标量化至 1 px、列表按 tick 去重。一条 180 秒航迹的常规样本约 1,801 个。单局硬上限 210 秒，存储时校验样本顺序和末帧。只留该版本最佳的一条，成绩与轨迹同笔替换。更慢或同成绩保留先前记录。
4. 回放按比赛有效 tick 对相邻样本插值。航迹无碰撞、无奖励，可关闭。分支切换以 `branch` 的改变标记，碰撞复位用 `pose=reset` 标记，回放在这些点跳到新位置，两条不连通的路线间不画穿墙插值。暂停期间航迹和比赛同步停下。版本不匹配时当前新赛道从无航迹开始。
5. 双人各自的镜头跟随自己的飞鱼，边缘小标和分段时间显示队友位置。每步先检查两席合法冲线并封存 `finish_tick`，再处理当步离席与超时。两人都冲线按有效 tick 比较，同 tick 为并列。首人完成后，另一人的截止步为 `min(首人冲线 tick + 1200, 起跑 tick + 12600)`，在截止步过线仍属完赛。一人完赛一人未完赛时，完赛者胜。双未完赛且均到时限时按已过门数、当前公共进度（取整至 px）比较，仍同为平局。
6. 主动离席时还没有有效 `finish_tick` 的选手弃赛，对手获胜。已经冲线的选手可以看对手跑完或直接离开，已封存成绩继续参与排名。已完成席位离线不冻结仍在比赛的选手，剩下的人可跑到冲线或上述截止步。仍在参赛的席位暂断时继续按房间规则暂停，重连超时按未完赛离席处理。两人都离席后回收房间。多人结果不写入单人最佳。

## 数据、画面与实施顺序

建议 `game_core/modes/tide_race.py`、`assets/modes/tide_race/`。每个路段包含长、浪型、相位、当地水流、障碍、上下路起止、局部安全点与下个计时门。把固定规则、单人航迹读写、渲染分开。快照给 `race_phase / start_tick / deadline_tick / track_version / racers / ranking / result`。各飞鱼有逻辑位置、路线 ID、速度、姿态、连击、过门记录和完赛 tick。客户端只能发送驾驶输入。

最低素材包含两套剪影可区分的飞鱼、三类起落动作、明显的浪尖泡沫和分流标、赛道背景、计时门、灯塔与终点。HUD 显示有效时间、分段和当前连击。双人同时冲线时结果直接显示「并列」。4K 仅扩大绘制分辨率，物理浪形与手机相同。

| 实施段 | 收口条件 |
| --- | --- |
| R-A | 灯塔短段真实起跳、俯冲、三连浪，基础巡航也能通过终点 |
| R-B | 三条赛道、分流、回退、顺序过门、单人成绩和离线航迹 |
| R-C | 主端双人同场、独立相机、弃赛和计时边界，两个客户端只收到一个一致赛果 |
| R-D | Phaser 单人读同一数据，与 Python 共用一组输入时间线和终点结果对照 |

## 验收 R1–R8

| 编号 | 操作 | 通过表现 |
| --- | --- | --- |
| R1 | 灯塔赛道只巡航一遍，再按提示操作三连浪 | 两次均能过段，后一次连击、速度与该段耗时出现可测差别 |
| R2 | 同一赛道分别走海面和水下捷径。定向布局在门后放障碍，碰撞复位到该门前的同路安全点，再向前过门 | 两路正确汇合，第二次向前过同一门时保留原来的过门时刻和门数 |
| R3 | 在分岔入口和浪尖快速点按／长按，碰障后复位 | 每次边沿只起跳一次，复位发生在本分支，比赛时间连续 |
| R4 | 单人依次取得 102 秒、108 秒、99 秒。重开应用再跑 | 最佳与航迹成对保留为 99 秒。暂停 5 秒不会让航迹先走 |
| R5 | 调高赛道版本再开，模拟一次存储不可用 | 新版没有旧路线残影，记录错误有提示，当局仍可跑完 |
| R6 | 两端同 tick 冲线，再试仅一人完成和两人都到时限 | 分别给并列、完赛者胜、按已过门与进度排名，双方一致 |
| R7 | P1 第 6,000 步冲线、第 6,001 步离开。P2 分别在第 7,200 步冲线和等到截止。再试 P1 过线前离开 | 首两局 P1 的冲线时刻保留，P2 可继续跑，截止步冲线有效。第三局才判 P1 弃赛。多人结果不覆盖单人最佳 |
| R8 | 原生、主 Web、Phaser 用同一输入经过三浪一门，另试横竖屏触控 | 过门 tick 差 ≤1、同分支、同连击。三条赛道可从各自单人首页离线进入 |
