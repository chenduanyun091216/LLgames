## 一场比赛

`boss_duel` 是局域网双人非对称对战。房主从巨鲸、机械蜥蜴、八岐大蛇中选一位，全场共用同一竞技场、选定首领和规则。第一回合 P1 当首领、P2 当冒险者，第二回合交换。两人都实际操纵一次同一首领，再比较各自冒险者回合的表现。

操作首领的乐趣在于预判。巨鲸可以先在左路放水柱，再把一颗将沿斜线反弹的珍珠投向右边出口。冒险者看到预警后仍有时间决定往哪边走。出手后规则锁定目标。首领血量、伤害、英雄射速和技能专用于这场对战。

| 阶段 | 权威流程 |
| --- | --- |
| 准备 | 房主选 `whale / mecha / orochi`，两席准备。两人进入相同竞技场，先显示当前角色和三个本局关键操作 |
| 回合一 | 倒计时 3 秒，正式对战最多 90 个有效秒。英雄倒下、首领倒下或时间用尽，封存第一份成绩 |
| 换边 | 结果卡显示首轮生存、伤害、角色交换。5 秒后进入第二次 3 秒倒计时。两人可各按一次「已了解」提前结束这 5 秒。公共暂停仍冻结倒计时 |
| 回合二 | 使用完全相同的首领、地图、初始状态、固定开场朝向和初始资源。重新分配席位输入，第二回合从有效时刻 0 开始 |
| 总结 | 服务器比较两份英雄成绩，公布双方角色、结果和决胜指标。可同首领再赛，或回房换另一位 |

## 英雄、首领与瞄准

- 逻辑竞技场 800×540。英雄初始点 (400,430)，活动区中心坐标限制在 x=18–782、y=170–520。首领初始中心 (400,90)，活动中心 x=100–700、y=65–125。墙和预警带的有效区域按同一逻辑坐标显示。角色出生到绿灯之前不会受到伤害。
- 英雄 5 HP，移动 210 px/s，半径 12。J／射击键或 `held` 位 1 持续向上射击，每 12 tick 一发、伤害 1。K／闪避按下发 `dash`，沿当前移动方向冲 72 px，持续 12 tick、前 6 tick 免伤、冷却 150 tick。方向中立时用最后移动方向。受伤后保护 54 tick。两台移动设备上可在本模式为英雄开启自动射击，状态有可见标志。
- 首领 150 HP，弱点命中框在身体正面（基础 108×58），移动速度 90 px/s。WASD／左摇杆移动本体。鼠标指向场内选落点。纯键盘用方向键移动屏上准星。触控可轻点场内或在右侧瞄准区拖动准星。J、K、L／三个技能按钮分别发 `cast_1/2/3`。移动和选点独立，单指也可先选点再按技能。准星初始在场地中央，显示当前选点及可达范围。
- 首领能量上限 100，起始 70，每秒回 8。开局前 60 tick 为可移动准备期，英雄与首领均不能造成伤害，该保护位于 90 秒回合内。触发有效施放后立即扣能并开始自身冷却，两次施放至少间隔 24 tick。能量不足、冷却中或技能槽满时，在对应键上反馈原因，资源维持原值。
- `mode_action.target` 为整场归一化千分坐标。服务器从施放当刻记录 `origin / target / start_tick / active_tick / end_tick / cast_id`。技能从该记录产生碰撞和预警。移动首领或下一帧移动准星都不能修改已发出的危险区。英雄的射击与命中由相同权威步判定。

## 三套可操作技能

下表时间顺序为「预警／生效时长或发射行为／从接受施放开始的冷却」，均为有效游戏时间。普通技能命中扣 1 HP。每个持续危险区按 `cast_id + target_slot` 去重，同一条激光或同一根水柱只造成一次伤害。发射物每枚可命中一次且受英雄保护时间约束。

| 首领与键位 | 时间、能量 | 玩家选点后发生什么 |
| --- | --- | --- |
| 巨鲸 J 水柱 | 0.85 s／0.65 s／3.0 s，22 能 | 在所选 x 出现宽 56 的蓝色浪纹，再由下朝上喷发。位置锁定，适合逼人离开一侧 |
| 巨鲸 K 反弹珍珠 | 0.9 s／最长 3.0 s／3.5 s，26 能 | 从发起位置朝选点发一颗半径 14 的珍珠，速度 235 px/s，在场边最多反弹两次。预警标出第一段和首次反射方向 |
| 巨鲸 L 潮汐月刃 | 1.2 s／2.0 s／7.0 s，42 能 | 两排错开的月刃自上而下，选点 x 决定至少 112 px 宽的安全通道。蓝白泡沫标出通道两侧 |
| 机械蜥蜴 J 轨道鞭 | 0.9 s／0.45 s／3.0 s，22 能 | 从当时的握柄到锁定点打出可读鞭线，有效宽 32。预警和判定使用同一折线 |
| 机械蜥蜴 K 定点导弹 | 1.0 s／两枚错开 0.4 s／4.0 s，28 能 | 在选点两侧各标半径 34 的落圈后依次落弹。发出后按标记落地。圆心靠近边缘时夹入场内 |
| 机械蜥蜴 L 脉冲环 | 1.15 s／1.4 s／7.0 s，40 能 | 从选点扩一圈电弧，带明确缺口，缺口朝场内可达的一侧。环最大半径 145，接触带宽 18 |
| 八岐大蛇 J 蛇首砸击 | 0.85 s／0.35 s／2.8 s，20 能 | 一颗蛇头朝锁定圆俯冲，圆半径 42，碎石消散后安全 |
| 八岐大蛇 K 双束交叉 | 1.1 s／0.55 s／4.5 s，30 能 | 两条预警线穿过选点形成交叉，生效期间角度固定，每束宽 22 |
| 八岐大蛇 L 雷暴 | 1.3 s／三次脉冲共 1.5 s／7.5 s，45 能 | 在选点周围出现三块固定危险区，提前依次编号。最靠近边界时向场内收束，保留明确的逃生路线 |

首版最多两个预警／生效中的施放组，范围大招同一时刻最多一组。大招数据附带安全口，至少保留一个 96 px 宽的实际开口。图中的宽度量两侧危险边缘的距离，判断英雄中心可通过的区间时两端各扣 12 px 身体半径。危险图形要有区域轮廓、计时节奏和声音提示。

巨鲸月刃在接受施放时检查从英雄当前位置走到安全口要多久。取首排最早可能命中英雄当前高度的步数 `T`，预留 12 tick 反应时间，可走距离 `d = 210 × max(0, T − 12) / 60`。以英雄当前 x 为中心取左右各 d 的可达区间，并裁到活动边界。先将 112 px 宽通道的中心限制在 [56,744]。两侧各扣 12 px 身体半径和 4 px 余量，得出宽 80 px 的目标区。如果目标区与可达区间不相交，只朝英雄方向平移到两者刚相交。此时锁定通道、显示真正的预警。以普通移动能力验算，闪避可以留给下一招。玩家自己在预警期间改变路线不会带动通道。

例如英雄在 x=18、最早命中距施放 72 tick、首领选最右侧时，修正后的通道中心为 268。英雄中心走到 228 即可通过，身体边缘与危险区仍有 4 px 距离。叠加第二招时，按两组已知轨迹检查至少一条从当前位置能及时通过的路线。没有可走路线就拒绝新施放并提示「通道占用」，能量和冷却维持原值。用场地两侧与中央分别验证，弱点、危险区和自己的准星在无颜色状态下也应能区分。

## 如何决定胜负

1. 每回合保存英雄席位、生存 tick、是否击倒首领、击倒 tick、对首领造成的实际伤害、英雄剩余 HP。伤害上限为首领当时剩余血量。一次固定步先收集双方命中，再同时结算，最后判定结束。首领与英雄同 tick 归零，英雄获得「击倒首领」，剩余 HP 记 0。
2. 成功击倒首领者优先。两人均击倒时先比用时少，再比剩余 HP 多，再相同则平局。两人均未击倒时先生存更久者胜。同样久时比实际伤害高，再比剩余 HP 多，仍同为平局。回合时间上限为 5,400 tick。两人都活满时不能只用存活时长决定胜负。
3. 示例。甲存活 53 秒、打掉 97 HP，乙存活 68 秒、打掉 80 HP，乙胜。甲乙都活满 90 秒且没有击倒，甲打掉 112、乙打掉 95，则甲胜。两人都击倒，一人 51 秒、另一人 49 秒，49 秒胜。结算页高亮第一项产生差异的指标。
4. 换边清空场上技能、子弹、命中记录、能量、冷却、免伤、按键、准星和当回合计时。`match_id` 保持，`round_id` 和 `epoch` 变更。第一回合成绩作为只读记录保留。断线、旋转或窗口挂起冻结对局。重连按当前席位、回合和岗位重建界面。
5. 一方主动离开或最终重连超时，比赛记该方弃权，余下玩家看到弃权胜和实际进行过的回合。两人同时不在且房间回收，则该场记中止。换边期间同样适用。通过同一结算事件结束，重复离开或旧回合消息无法再改比分。

## 代码复用、画面与实施顺序

建议 `game_core/modes/boss_duel.py` 管模式回合、角色映射和输入，技能参数放 `assets/modes/boss_duel/`。已有[巨鲸与机械蜥蜴](../../../game_core/abyss_bosses.py)、[八岐大蛇](../../../game_core/orochi.py)提供贴图、姿态、珍珠反弹和危险区绘制参考。取可独立调用的几何或动画函数，特别核对全局时间和战役场地边界。玩家输入独立驱动施放。战役 AI 的随机选技、自动追踪、回血和召援仍由原战役调度。

快照包含 `round_id / role_by_slot / arena / clock / hero_hp / boss_hp / energy / cooldowns / pending_casts / active_shapes / shots / first_round_result / final_result`。预警起止用权威 tick 表示，网络插值只作用于移动显示。一份最新快照要能在回合中途重建剩余预警、能量条和第一回合成绩。HUD 对冒险者显示求生时钟和威胁方向，对首领显示三键、费能、冷却、选点和待生效顺序。准备三张首领卡、三种瞄准样式、换边说明和一张能比较两回合的结算页。

| 实施段 | 产物 |
| --- | --- |
| B-A | 两端进入巨鲸样局，主动选点水柱，英雄可躲、可命中、可完整换边 |
| B-B | 补巨鲸三个技能、锁点、资源、赛果比较和对称重置，覆盖同时倒地 |
| B-C | 机械蜥蜴与八岐大蛇完整进入选择页，各自三招，九招均有相应预警和可见反馈 |
| B-D | 混合设备验收，手机能选中场角、换边后键位正确，重连后能继续此回合。接 Phaser 联机跳转 |

## 验收 B1–B8

| 编号 | 操作 | 通过表现 |

| B1 | P1 选巨鲸并瞄准左侧放水柱，预警后把瞄点移到右侧 | 两端水柱都在左侧同一位置生效。离开标记的英雄能躲开 |
| B2 | 对三首领的九招从两侧施放并移动首领本体。月刃另测英雄在 x=18／782、闪避冷却、首领指向对侧，预警 12 tick 后开始走 | 每招预警、命中和消散对齐。两种极端位置均有普通移动可走到的通道，持续危险区只结一次该次命中 |
| B3 | 冷却中连按、低能量按大招、英雄尝试触发首领技 | 没有额外出招和重复扣能，自己的界面明示不可用原因 |
