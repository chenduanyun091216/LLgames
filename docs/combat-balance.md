# 海洋生物入侵 · 战斗平衡对照

## 数值口径

三项并列时依次为**简单 / 中等 / 困难**。所有“原值”取本次调整前本地可运行版本，包括当时已有的武器和角色强化。PC、原版 Web 和局域网共用战斗核心。独立 Phaser 网页版读取相同配置，原有实现差异在对应表下注明。

用**第一关 Boss 需要几发裸装步枪**可以直观看到四种模式的区别。以下按渔民在 Boss 完整入场后每发命中计算，不含护盾、增益和技能。

| 模式 | 第一关 Boss HP（原 → 新） | 步枪每发伤害（原 → 新） | 击败所需命中（原 → 新） |
| --- | --- | --- | --- |
| 简单 | 18 → 16 | 1.5 → 1.5 | 12 → 11 发 |
| 中等 | 24 → 24 | 1.5 → 1.5 | 16 → 16 发 |
| 困难 | 28 → 32 | 1.5 → 1.5 | 19 → 22 发 |
| 无限首章 | 30 → 30 | 1.3 → 1.5 | 24 → 20 发 |

**独立 Phaser 版的原值差异**包括步枪每级射速 +10%，无步枪红弹、散弹加发及狙击急速。旧版火盾按等级抵挡 1 / 2 / 3 次，仅满级辐射结界清弹，冰结界没有易伤。无限裸装伤害沿用原战役值，Boss 另有限伤。新版按上表计算。独立版部分 Boss 动作时序、被动和碰撞仍使用其自身实现。

独立 Phaser 版原先在无限首轮的普通海域沿用对应的战役怪池，工厂碎片也不占刷新名额。现已接入上述无限怪池和同屏上限规则。普通冻结的单怪易伤与角色强化的全场冰结界分开计算。
