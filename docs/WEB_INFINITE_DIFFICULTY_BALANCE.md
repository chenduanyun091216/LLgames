# 海洋生物入侵 · Web 无限模式难度优化实施方案

2026-11-08 · v1 · 待实现

本文供实现 agent 直接执行。范围为 Web 单人无限模式。保留全武器、全角色、免费弹药、计时召唤 Boss、八个 Boss 循环和不限次数的手动续关。首轮难度以中等战役的反应窗口为参考，使用独立参数。第 9 个 Boss 回到巨型龙虾，显示为第 2 轮第 1 个 Boss。战役三档、自定义、PC 端和离线分发属于回归范围。

本文给出一套完整的首版参数。涉及无限模式的规则，以本文为准。[Web 战役平衡方案](WEB_DIFFICULTY_BALANCE.md) 第 6 节的无限模式条目是早期提案。

## 1. 现状与改动目标

| 当前行为 | 问题 | 首版目标 |
| --- | --- | --- |
| 无限模式借用困难预设，开局与击败 Boss 后各等 25 秒。 | 调整战役困难可能影响无限，且首轮 Boss 的攻击频率偏高。 | 独立配置，保留 25 秒周期。 |
| 开局目标 5 只，约 50 秒进入 20–26 只波动，每次最多补 2 只，击杀还会把刷新间隔从 900 ms 压到最低 280 ms。 | 玩家同时面对密度、弹幕和补怪速度上升，低帧设备受影响。 | 随击败的 Boss 数逐步增压，每次补 1 只，设置实体和开火预算。 |
| 首轮 Boss 生命为 25、38、58、85、125、195、300、400。第 9 个 Boss 生命至少 413，第 1 个只有 25。 | 循环开头突然比整轮末尾更难，同一个 Boss 失去原有定位。 | 各 Boss 按自己的首轮生命增长，每轮线性加成并封顶。 |
| 杂兵按武器分别累计伤害，换枪后需要重新打对应的阈值。第二轮起部分玩家输出每轮增长 30%。 | 杂兵与 Boss 的成长和玩家成长互相抵消，伤害来源难比较。 | 统一生命结算，取消轮次给玩家加伤。 |
| 单个敌人越线或 Boss 接触可直接触发续关。无限计时用实时时钟，开商店、暂停与切后台会影响压力。 | 同一次失误的惩罚受设备和场景影响，续关也可能接着被近身弹击中。 | 越线按血量惩罚，统一保护和有效战斗时钟，续关保留进度并留出操作窗口。 |

现行入口及覆盖逻辑在 [game_core/game.py](../game_core/game.py)，Boss 基础定义在 [game_core/config.py](../game_core/config.py)，时钟入口在 [game_core/main.py](../game_core/main.py)，实体与专属 Boss 规则在 [game_core/entities.py](../game_core/entities.py) 和 [game_core/special_bosses.py](../game_core/special_bosses.py)。

## 2. 模式流程与唯一进度口径

- 开局满血 5 HP，默认手枪和渔夫，武器与角色均已解锁，射击免费。允许切回手枪。保留自动射击和现有触控入口。
- 使用单一累计值 `bosses_defeated`，开局为 0。当前或待出场 Boss 的累计编号为 `bosses_defeated + 1`。当前轮序号为 `bosses_defeated // 8 + 1`，轮内序号为 `bosses_defeated % 8 + 1`。生成 Boss、暂停、续关与换背景都不增加已击败数量。Boss 确认死亡后只结算一次。
- 开局进入杂兵阶段，首个 Boss 在有效战斗时间满 25 秒时生成。每次击败 Boss 后，下一次召唤安排在再过 25 秒。Boss 战结束前不启动下一段倒计时，杂兵击杀数不构成召唤条件。预告在剩余 3 秒显示。
- Boss 进场时清理玩家弹、敌弹和上阶段残留的杂兵，清理不计分。已生效的角色增益、冷却和血量继续计时。Boss 增援从进场完成后按表延迟刷新。Boss 死亡后清场，立即开始下一段 25 秒杂兵阶段，1.2 秒后刷第一只。开局也是 1.2 秒。
- 击败第 8、16、24 个 Boss 时进入下一轮。场景按当前轮内序号正常轮换。手动切背景只改外观与音乐，杂兵池、难度、积分和 Boss 顺序继续由进度决定。
- 首版把连续生存作为主要目标，保留继续游玩入口。成绩界面显示总积分、已击败 Boss 数、到达轮次、续关次数。成绩只在当前运行内保存。

## 3. 杂兵、刷新与射击预算

令 `n = bosses_defeated`，`cycle = n // 8`。密度和刷新间隔随已击败数量增长。所有时间以有效战斗毫秒为单位，实体移动以 60 次战斗更新每秒为参考。

| 参数 | 规则 |
| --- | --- |
| 杂兵阶段在场上限 | `min(14, 4 + n // 2)`。首轮依次为 4、4、5、5、6、6、7、7。 |
| 杂兵阶段刷新间隔 | `max(800, 1300 - 50 * (n // 2))` ms，满员后等空位，恢复时仅补一只。 |
| Boss 增援上限 | 取第 4 节对应上限加 `min(2, cycle)`，绝对上限 6。 |
| Boss 增援间隔 | 取第 4 节对应间隔，每轮缩短首轮间隔的 5%，最低 75%。 |
| 刷怪池 | 复用无限模式现有末关池。按生成次数统计普通、重型、特殊敌人，实际概率见下方。 |
| 杂兵基础生命 | 普通 3、大型 9、小棕棕 8。实际生命按第 4 节的生命倍率计算，保留小数用于伤害结算。 |
| 位移 | 基础速度随机浮动 ±12%。按生成到防线的距离换算纵向速度，以 844×390 的横屏为参考。出生后可被攻击至越线至少 4.5 秒。 |
| 普通弹发射 | 初次开火至少可见 3.8 秒，之后间隔在 8–12 秒均匀抽取，乘第 4 节的攻击间隔倍率。首次可见时间不乘倍率。 |
| 发射预算 | 滚动 1 秒内杂兵阶段最多 2 次杂兵开火，Boss 阶段最多 1 次。超过预算顺延 180 ms 后重试，单次开火最多 3 发。 |
| 敌方在场弹数 | 杂兵弹最多 24 个，Boss 攻击物最多 36 个。攻击物包括独立弹体、炸弹和月牙。超出则整组延后 250 ms 重试或在该招已结束时取消，现存弹体照常结算。预警中的已承诺弹体预留配额。 |

普通、重型、小棕棕采用单次随机抽取，首个 Boss 前重型 10%、小棕棕 0%，其后重型 14%、小棕棕 3%，轮内第 8 个 Boss 对应阶段的小棕棕比例为 5%。重型与小棕棕都算特殊生成。特殊生成之间至少插一只普通怪，同屏小棕棕至多 1 只。抽到被约束的类型时改刷普通怪，实际概率以多局生成记录为准。快速变体只对普通怪抽取，开局前 6 次生成禁用，其后概率 8%，速度乘 1.50，仍受 4.5 秒下限约束。

普通弹扣 1 HP，普通敌人接触扣 1，大型敌人和 Boss 接触扣 2。Boss 接触沿最近可移动方向分离碰撞。越线时立即移除并记一次漏怪，扣 1 HP，重型和小棕棕也按 1 HP 结算。实际扣血后给 650 ms 全局保护。保护期间其他越线目标依然移除并计数。激光每次施放至多命中一次，重火球、回旋斧落地和炸弹单次最多扣 2 HP。

## 4. Boss 参数与跨轮增长

| 轮内序号 | Boss | 首轮 HP | 首轮基础出招间隔 ms | 首轮增援间隔 ms / 上限 | 首轮目标击杀中位时长 |
| --- | --- | ---: | ---: | ---: | --- |
| 1 | 巨型龙虾 | 30 | 4400 | 5500 / 1 | 10–20 秒 |
| 2 | 巨型螃蟹 | 46 | 4100 | 5000 / 1 | 15–26 秒 |
| 3 | 巨型章鱼 | 66 | 3900 | 4600 / 2 | 20–32 秒 |
| 4 | 巨型鲨鱼 | 90 | 3700 | 4300 / 2 | 25–40 秒 |
| 5 | 海龙 | 116 | 3500 | 4000 / 2 | 32–48 秒 |
| 6 | 深渊之主 | 144 | 3400 | 4200 / 2 | 38–58 秒 |
| 7 | 牛魔王 | 170 | 5800 | 4300 / 2 | 43–65 秒 |
| 8 | 小粽粽 | 192 | 3700 | 4600 / 2 | 48–75 秒 |

- 生命倍率为 `(100 + 20 * min(cycle, 6)) / 100`，第 7 轮起封顶 2.20。Boss 向上取整，实现时用整数百分比避免浮点误进位。各杂兵保留小数。小粽粽每个分身初始生命为总生命的一半，任何结算后总生命等于两侧当前生命之和。
- 普通出招间隔和杂兵复射间隔乘 `max(70, 100 - 5 * cycle) / 100`，以毫秒取整。移除随单场战斗时长加速到 900 ms 的路径。首次攻击至少在 Boss 入场完成 1.6 秒后。反射、复活、预警、攻击持续和招后恢复时长保持固定。
- 第 9 个 Boss 仍是龙虾，生命 36，基础攻击间隔 4180 ms。第 17 个也是龙虾，生命 42，间隔 3960 ms。第 49 个龙虾生命 66，间隔 3080 ms。第 50 个及以后继续使用各自 Boss 的首轮基础值乘封顶倍率。
- 龙虾只用双发散射。螃蟹首次激光在入场后至少 8 秒。章鱼加入重火球，先发一次普通散射。鲨鱼、海龙加入追踪弹，普通追踪最多 650 ms，之后沿当前方向飞行。深渊之主保留宽扇和交叉弹幕，追踪每三轮主动攻击最多一次。深渊之主在无限模式没有战役专属吞噬回血。
- 牛魔王保留飞斧、漩涡、闪电、双束激光。冰斧锁操作 300 ms，移速降低 20% 持续 1.5 秒，落地伤害每把只算一次。漩涡活跃 2.3 秒，单次最多扣 1 HP，停止吞怪回血。漩涡、闪电、激光之间互斥，危害结束后留 1.7 秒回击时间。护盾在 65% 和 30% 触发，最多 3 秒，期间仍可攻击。
- 小粽粽双体均接受武器和技能，剩一体时承伤 ×2。反射护盾预警后持续 2.5 秒，每秒最多反弹两发。剩单体 16 秒后给出 2 秒复活预警，每战最多复活一次，恢复总生命的 10%。保留月牙、炸弹、暴雪。月牙宽度按战斗区基准 140，炸弹半径按基准 72，暴雪移速与射速降低 20%，持续 3 秒，避开反射护盾与月牙发射窗口。
- 复用战役现有的动态危险区计算，以 1000 ms 为重火球、激光、飞斧、漩涡、闪电、月牙的基础预警，锁定后炸弹使用 800 ms。实际时长取基础值和「到安全点所需移动时间 + 300 ms + 剩余锁操作时间」中的较大值。按玩家当前受限速度估算，预警与伤害判定共用同一几何数据。至少留 1.5 倍玩家碰撞宽度的通道。危险区完全封路时取消该次招式并走正常冷却。高危招式预警及生效期间暂停新增增援，原有普通怪仍受开火预算约束。

## 5. 玩家输出、礼包与续关

| 武器 | 基础射击间隔 | 伤害 |
| --- | ---: | --- |
| 手枪 | 300 ms | 1 |
| 步枪 | 200 ms | 1.35 |
| 散弹 | 360 ms | 3 枚，每枚 0.85 |
| 狙击 | 520 ms | 首个目标 3，每穿过一个杂兵，后续伤害 ×0.65 |

- 杂兵和 Boss 接收同一套单位伤害。杂兵共享生命，取消武器分桶。火人普攻 ×1.2。无限模式角色技能沿用 Web 战役基础伤害、持续时间、范围和目标上限，冷却取战役中等基础值的 0.65 倍，仍从效果结束起计。渔夫手雷按战役的即时起算规则。武器、角色、礼包伤害不随轮次增加。技能和增益仍按其本来规则生效。
- 无条件允许切换已解锁的武器。保留既有切换冷却。水人每击杀 14 只杂兵恢复 1 HP，每个 25 秒杂兵阶段及其后 Boss 战合计最多触发两次。Boss 不计入这 14 只。基础血上限保持 5。
- 礼包在有效战斗时间第 18 秒首次尝试出现，之后每 22 秒尝试一次。场上已有礼包则跳过本次。权重与已实现的战役规则一致，火、冰、治疗、加速、闪电分别为 25/25/20/15/15。同种进攻礼包不连续。火弹伤害 ×1.25 持续 7 秒，冰弹减速 25%，普通怪冻结 0.8 秒，小棕棕免疫冻结。闪电两次、间隔 3 秒，每次最多清算三个靠近底线的杂兵各 3 HP。没有杂兵时对 Boss 造成 2 HP。角色与礼包同类射速增益取较强者。
- 击败普通怪加 10 分，大型怪、小棕棕加 30 分，Boss 加 100 分并恢复 1 HP。刷怪、清场、越线和续关均不加分。分数不兑换道具。
- 生命归零进入现有续关提示。可无限次选择继续，主动结束则展示本局成绩。每次确认继续只增加一次续关次数，回复 5 HP，显示 3 秒倒计时。保留积分、轮次、Boss 当前生命、分身生命、攻击阶段及技能冷却。清掉距玩家中心 150 逻辑像素以内的敌弹，清掉已经越线的杂兵，倒计时结束后给 2 秒保护。倒计时期间不刷新、不开火、不结算礼包。续关后可继续刷分，成绩上标明是否为零续关。
- 调试跳关和狂暴继续可用时，标记该局为调试局，成绩面板明确显示，试玩样本排除。手动换背景保持纯外观操作。

## 6. 时钟、界面与代码落点

1. **进度和参数**。在 `game_core/config.py` 定义独立无限模式参数，在 `game_core/game.py` 的 `_begin_infinite_run`、`_trigger_infinite_boss`、`_kill_boss` 接入统一累计进度。移除仅用于旧无限增长的公式。以同一已击败数量派生 Boss 编号、轮次、难度和密度，避免重复写入互相矛盾的计数器。
2. **生成和伤害**。修改 `spawn_enemy`、`_spawn_infinite_enemies_to_target` 及两条战斗更新路径。使用已存在的共享生命结算和弹幕调度方法，给无限模式显式传入它自己的参数。Boss 和杂兵攻防、道具、角色技能统一使用独立模式规则。避免把模式名设成战役困难，或通过伪造战役档位来驱动分支。
3. **计时与续关**。让 `game_core/main.py` 的固定步进覆盖无限模式。复用 `config.game_ticks()`，有效时间只在实际战斗更新时推进。暂停、商店、页面不可见、等待续关和续关倒计时都停止战斗时钟，倒计时用独立实时时钟，避免把倒计时加进下一次刷怪。关闭商店返回进入前的实际状态。低帧恢复每帧追赶最多 4 步，后台恢复首帧清除积压。
4. **可达性与界面**。复用 `_hazard_warning_ms`、`_queue_boss_shots`、激光危险区和实际战斗边界。专属招式在 `game_core/special_bosses.py` 读取独立规则。旋转时映射在场实体和锁定危险区的相对坐标，保留倒计时与阶段，旋转当帧跳过额外碰撞。HUD 显示轮次、轮内 Boss 序号、积分和续关数。入口文案改为「全装备 · 免费弹药」，避免把缩短冷却写成无冷却。
5. **隔离与回归**。原来将战役与无限分开的逻辑按功能提取必要的共用部分，各模式配置留在各自入口。更新旧无限测试里的 300/400 HP 断言，保留战役与自定义的既有断言。实施后更新 [WEB.md](WEB.md) 的无限模式玩法说明。
